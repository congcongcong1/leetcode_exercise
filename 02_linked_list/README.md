# 链表 (Linked List)

## 核心知识点
- 链表通过指针连接节点，不需要连续内存
- 插入/删除 O(1)（已知位置），查找 O(n)
- **虚拟头节点 (dummy head)** 可以简化边界处理

## 常用解题模式
- **快慢指针**：找中间节点、检测环
- **反转链表**：迭代法（三指针）和递归法
- **虚拟头节点**：避免头节点特殊处理
- **合并链表**：归并思想
