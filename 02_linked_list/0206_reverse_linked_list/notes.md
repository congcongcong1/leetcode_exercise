# 206. Reverse Linked List (反转链表)

> 难度: Easy | 分类: 链表 | 日期: 2026-03-05

## 题目摘要

反转一个单链表，返回反转后的头节点。

## 解题思路

### 第一反应
- 链表不能像数组一样原地交换，需要改变指针方向
- 迭代法最直观：用两个指针逐个翻转

### 最终解法
- **迭代法**：设 `prev = None`, `curr = head`，每次将 curr.next 指向 prev，然后两个指针都前进一步
- **递归法**：递归到末尾，回溯时通过 `head.next.next = head` 翻转

### 复杂度分析
| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 迭代法 | O(n) | O(1) |
| 递归法 | O(n) | O(n) |

## 关键知识点

- [x] 迭代反转的三步操作：保存next → 翻转指针 → 移动指针
- [x] 递归法的关键：`head.next.next = head` + `head.next = None`
- [x] 链表题目经常需要辅助函数来创建/打印链表

## 踩坑记录

- ⚠️ 迭代法中必须先保存 `curr.next`，否则翻转后就找不到下一个节点了
- ⚠️ 递归法别忘了 `head.next = None`，否则会形成环
