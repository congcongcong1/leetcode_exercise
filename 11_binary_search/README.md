# 二分查找 (Binary Search)

## 核心知识点
- 前提条件：**有序**（或具有单调性的搜索空间）
- 时间复杂度 O(log n)
- 注意**边界条件**：左闭右闭 `[left, right]` vs 左闭右开 `[left, right)`

## 常用解题模式
- **标准二分**：查找目标值
- **查找边界**：第一个 ≥ target / 最后一个 ≤ target
- **二分答案**：在答案空间上二分
