# 20. Valid Parentheses (有效的括号)

> 难度: Easy | 分类: 栈 | 日期: 2026-03-05

## 题目摘要

判断一个只包含括号字符的字符串是否有效（括号类型匹配且顺序正确）。

## 解题思路

### 第一反应
- 括号匹配第一反应就是用栈，左括号入栈，右括号匹配出栈

### 最终解法
- 核心思路：**用栈模拟匹配过程**
- 关键步骤：
  1. 遇到左括号 → 入栈
  2. 遇到右括号 → 检查栈顶是否是对应的左括号
  3. 最后检查栈是否为空

### 复杂度分析
| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 栈 | O(n) | O(n) |

## 关键知识点

- [x] 栈的 LIFO 特性天然适合括号匹配问题
- [x] 用字典存储右括号 → 左括号的映射，代码更简洁

## 踩坑记录

- ⚠️ 别忘了检查栈是否为空（例如只有右括号 `")"` 的情况）
- ⚠️ 最后要检查栈为空，而不是直接返回 True（可能有多余的左括号）
