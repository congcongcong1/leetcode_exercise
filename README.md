# 🚀 LeetCode 练习仓库

> 面向实习准备的 LeetCode 刷题仓库，按算法分类组织，配套思考笔记与进度追踪。

## 📁 目录结构

```
├── 01_array/               数组
├── 02_linked_list/         链表
├── 03_stack_queue/         栈与队列
├── 04_hash_table/          哈希表
├── 05_string/              字符串
├── 06_binary_tree/         二叉树
├── 07_backtracking/        回溯
├── 08_greedy/              贪心
├── 09_dynamic_programming/ 动态规划
├── 10_graph/               图论
├── 11_binary_search/       二分查找
├── 12_two_pointers/        双指针 / 滑动窗口
├── 13_sorting/             排序
├── 14_math/                数学
├── 15_design/              设计题
├── templates/              模板文件
└── PROGRESS.md             刷题进度追踪
```

每道题一个文件夹，包含：
- `solution.py` — 解题代码（含多种解法 + 测试用例）
- `notes.md` — 思路分析与复盘笔记

## 🗺️ 推荐刷题路线

| 阶段 | 分类 | 目标题数 |
|------|------|---------|
| **阶段一：基础** | 数组、链表、栈与队列、哈希表 | 每类 8-10 题 |
| **阶段二：核心** | 二叉树、二分查找、双指针、字符串 | 每类 8-10 题 |
| **阶段三：进阶** | 回溯、贪心、动态规划 | 每类 10-15 题 |
| **阶段四：扩展** | 图论、排序、数学、设计题 | 每类 5-8 题 |

## ⏱️ 每日练习节奏

1. **新题 2-3 道** — 按分类顺序推进
2. **复习 1-2 道** — 回顾前几天做错 / 不熟的题
3. **笔记整理** — 每道题写 `notes.md`，重点记录**思路**而非代码

## 🔄 做题流程

```
读题(5min) → 独立思考(15min) → 编码(15min) → 提交验证 → 写笔记(5min)
```

> 💡 15 分钟没思路 → 看提示再尝试 → 仍无法解决 → 看题解**理解后默写**

## 🏃 如何开始

1. 进入对应分类文件夹
2. 复制 `templates/` 中的模板到新题目文件夹
3. 按模板格式完成代码和笔记
4. 在 `PROGRESS.md` 中更新进度

## 🚀 运行代码

```bash
cd 01_array/0001_two_sum
python solution.py
```

    滑动窗口的使用条件：
