# 排序 (Sorting)

## 核心知识点
- 常见排序算法及其复杂度：
  - 快速排序 O(n log n)、归并排序 O(n log n)、堆排序 O(n log n)
  - 冒泡排序 O(n²)、插入排序 O(n²)、选择排序 O(n²)
- **稳定性**：归并排序稳定，快速排序不稳定
- Python 内置 `sort()` 使用 Timsort
