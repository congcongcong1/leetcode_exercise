# 动态规划 (Dynamic Programming)

## 核心知识点
- **DP 五部曲**：
  1. 确定 dp 数组及下标含义
  2. 确定递推公式
  3. dp 数组初始化
  4. 确定遍历顺序
  5. 举例推导验证
- 本质：将大问题分解为子问题，记录子问题答案避免重复计算

## 常用解题模式
- **背包问题**：0-1 背包、完全背包
- **线性 DP**：爬楼梯、打家劫舍
- **区间 DP**：回文子串
- **序列 DP**：最长递增子序列 (LIS)、最长公共子序列 (LCS)
- **状态压缩 DP**：用位运算表示状态
