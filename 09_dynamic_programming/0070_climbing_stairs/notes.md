# 70. Climbing Stairs (爬楼梯)

> 难度: Easy | 分类: 动态规划 | 日期: 2026-03-05

## 题目摘要

爬 n 阶楼梯，每次可以爬 1 或 2 阶，问有多少种不同方法？

## 解题思路

### 第一反应
- 到第 n 阶要么从第 n-1 阶爬 1 步，要么从第 n-2 阶爬 2 步
- 这就是斐波那契数列！

### 最终解法
- **DP 五部曲**：
  1. `dp[i]`：到达第 i 阶的方法数
  2. 递推公式：`dp[i] = dp[i-1] + dp[i-2]`
  3. 初始化：`dp[1] = 1, dp[2] = 2`
  4. 遍历顺序：从前往后
  5. 举例验证：1, 2, 3, 5, 8, ...

### 复杂度分析
| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP 数组 | O(n) | O(n) |
| 滚动变量 | O(n) | O(1) |

## 关键知识点

- [x] 爬楼梯 = 斐波那契数列的变体
- [x] DP 空间优化：如果状态只依赖前几个值，可以用变量代替数组
- [x] DP 五部曲是解决所有 DP 问题的通用框架

## 踩坑记录

- ⚠️ 初始化别搞混：`dp[1]=1, dp[2]=2`，不是 `dp[0]=1, dp[1]=1`
