# 图论 (Graph)

## 核心知识点
- **表示方式**：邻接矩阵、邻接表
- **DFS/BFS**：图的遍历基础
- **拓扑排序**：有向无环图 (DAG)
- **并查集 (Union-Find)**：连通性问题

## 常用解题模式
- **岛屿问题**：DFS/BFS 标记访问
- **最短路径**：BFS（无权图）、Dijkstra（有权图）
- **连通分量**：DFS / 并查集
