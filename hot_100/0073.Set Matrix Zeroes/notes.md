# [73]. [矩阵置零]

> 难度: [Medium] | 分类: [数组/矩阵] | 日期: 2026-3-14

## 题目摘要 

给定一个 m x n 的整数矩阵 matrix ，如果一个元素为 0 ，则将其整个行和列都设置为 0 ；
请使用 原地 算法。

## 解题思路

### 第一反应
- 看到题目后最直觉的想法是什么？
 思路：原地算法所以空间复杂度是O(1),想到可以维护一个指示行和列是否包含0的数组
- 为什么这个想法行得通 / 行不通？
  行得通，但是空间复杂度是O(n+m)，最好还是O(1)，所以想到了将矩阵的第一行和第一列作为指示行和列是否包含0的数组，同时为了处理矩阵的第一行第一列是否含0，引入两个额外的布尔变量来最后处理第一行和第一列

### 最终解法
- 核心思路：
  1. 将矩阵的第一行和第一列作为指示行和列是否包含0的数组，同时为了处理矩阵的第一行第一列是否含0，引入两个额外的布尔变量来最后处理第一行和第一列


### 复杂度分析
| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
|指针数组 | O(mn) | O(m+n) |
|第一行和第一列指针 | O(mn) | O(1) |
