# 二叉树 (Binary Tree)

## 核心知识点
- **遍历方式**：前序、中序、后序、层序
- 递归三要素：返回值、终止条件、单层逻辑
- **BST 性质**：中序遍历有序

## 常用解题模式
- **递归**：自顶向下 vs 自底向上
- **BFS 层序遍历**：用队列逐层处理
- **DFS 深度遍历**：前/中/后序递归或迭代
- **构造树**：从遍历序列重建二叉树
