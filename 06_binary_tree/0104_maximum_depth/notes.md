# 104. Maximum Depth of Binary Tree (二叉树的最大深度)

> 难度: Easy | 分类: 二叉树, DFS, BFS | 日期: 2026-03-05

## 题目摘要

求二叉树从根到最远叶子节点的最长路径上的节点数。

## 解题思路

### 第一反应
- 树的深度 = 1 + 子树的最大深度，天然的递归结构

### 最终解法
- **递归 DFS**：`maxDepth(root) = 1 + max(maxDepth(left), maxDepth(right))`
- **迭代 BFS**：层序遍历，数层数

### 复杂度分析
| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 递归 DFS | O(n) | O(h) 树高 |
| BFS 层序 | O(n) | O(n) 最宽层 |

## 关键知识点

- [x] 二叉树问题的递归思维：将问题分解为左右子树的子问题
- [x] BFS 层序遍历的模板：队列 + 按层处理
- [x] 递归终止条件：`if not root: return 0`

## 踩坑记录

- ⚠️ 注意"深度"的定义是节点数还是边数（LeetCode 上是节点数）
