# 字符串 (String)

## 核心知识点
- Python 字符串不可变，拼接操作 O(n)
- 常与哈希表、双指针结合
- **KMP 算法**：O(n+m) 字符串匹配

## 常用解题模式
- **滑动窗口**：求满足条件的最长/最短子串
- **双指针**：回文判断、反转
- **哈希表统计**：字符频率、异序词判断
