# 贪心 (Greedy)

## 核心知识点
- 每一步都选择当前最优解，期望全局最优
- 贪心没有固定模板，重点在于**证明贪心策略的正确性**
- 常见证明方法：反证法、交换论证

## 常用解题模式
- **区间问题**：排序后贪心选择
- **跳跃游戏**：维护最远可达位置
- **分配问题**：排序后匹配
