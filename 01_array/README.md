# 数组 (Array)

## 核心知识点
- 数组是最基础的数据结构，连续内存存储
- 随机访问 O(1)，插入/删除 O(n)
- 注意**原地操作**与**额外空间**的取舍

## 常用解题模式
- **双指针**：快慢指针、左右对撞指针
- **哈希表辅助**：空间换时间，O(n) 查找 → O(1)
- **排序预处理**：排序后利用有序性简化问题
- **前缀和**：快速求子数组和
