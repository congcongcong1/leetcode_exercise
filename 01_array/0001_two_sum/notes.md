# 1. Two Sum (两数之和)

> 难度: Easy | 分类: 数组, 哈希表 | 日期: 2026-03-05

## 题目摘要

给一个数组和目标值，找两个数加起来等于目标值，返回它们的下标。

## 解题思路

### 第一反应
- 最直接的想法就是两层循环暴力枚举所有数对
- 这样做可以解决问题，但时间复杂度是 O(n²)，不够高效

### 最终解法
- 核心思路：**用哈希表存储已经遍历过的值及其下标**
- 关键步骤：
  1. 遍历数组，对于当前元素 `num`，计算 `complement = target - num`
  2. 检查 `complement` 是否已经在哈希表中
  3. 如果在，返回 `[hash_map[complement], i]`
  4. 如果不在，将 `num: i` 加入哈希表

### 复杂度分析
| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n²) | O(1) |
| 哈希表 | O(n) | O(n) |

## 关键知识点

- [x] 哈希表查找是 O(1)，可以把 O(n) 的查找优化掉
- [x] "空间换时间"是非常常见的优化思路
- [x] `enumerate()` 可以同时获取下标和值

## 踩坑记录

- ⚠️ 不能用同一个元素两次，所以要先查再存（不能先存再查）
