# [18]. [四数之和]

> 难度: [Medium] | 分类: [数组/链表/...] | 日期: 2026-3-5

## 题目摘要

给你一个整数数组 nums ，判断是否存在四元组 [nums[i], nums[j], nums[k], nums[l]] 满足 i != j、i != k 、i != l、j != k、j != l、k != l ，同时还满足 nums[i] + nums[j] + nums[k] + nums[l] == 0 。请你返回所有和为 0 且不重复的四元组。

## 解题思路

### 第一反应
- 看到题目后最直觉的想法是什么？
  类比15题学习到的双指针的方法，尝试可以先排序，再将四数之和转化为三数之和的target形式，再将三数之和转化为两数之和的形式，将复杂度降到O(n^3)
- 为什么这个想法行得通 / 行不通？
  行得通，因为排序后可以使用双指针，这种题目都是类似的

### 最终解法
- 核心思路：
  1. ...先对数组进行sort排序，使其从小到大排列
  2. ...使用双指针移动法


### 复杂度分析
| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 最优 | O(n^3) | O(1) |

## 关键知识点

- [ ] [知识点1：如 "排序是 O(nlogn)"]
- [ ] [知识点2：如 "双指针适用于有序数组,所以要先sort，这种题目都是类似解法，有几个数就枚举到只剩下两个进行双指针法，再用while跳过重复元素，每次枚举进行跳过以及剪枝操作等"]

## 踩坑记录

- ⚠️ [要先对数组进行排序再用双指针的方法]
- ⚠️ [剪枝操作每次枚举的数都要使用可大大加快速度，剪枝操作的判断条件要仔细，而且最后跳过每一个元素要确定是和前一个元素还是后一个元素比较]
