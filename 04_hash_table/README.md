# 哈希表 (Hash Table)

## 核心知识点
- Python 中 `dict` 和 `set` 底层是哈希表
- 查找、插入、删除均为 O(1) 平均时间
- 核心思想：**空间换时间**

## 常用解题模式
- **频率统计**：`collections.Counter`
- **去重 / 判断存在**：`set`
- **映射关系**：`dict` 存储 key→value 映射
- **分组聚合**：`defaultdict(list)`
