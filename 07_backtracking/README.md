# 回溯 (Backtracking)

## 核心知识点
- 回溯 = 递归 + 剪枝，本质是暴力搜索的优化
- **回溯三部曲**：路径、选择列表、结束条件
- 注意**去重**：排序 + 跳过相同元素

## 常用解题模式
- **组合问题**：从 n 个数中选 k 个
- **排列问题**：n 个数的全排列
- **子集问题**：收集所有节点
- **棋盘问题**：N 皇后、解数独
