# [209]. [长度最小的子数组]

> 难度: [Medium] | 分类: [数组/链表/...] | 日期: 2026-3-6

## 题目摘要

定一个含有 n 个正整数的数组和一个正整数 target 
找出该数组中满足其总和大于等于 target 的长度最小的 子数组 [numsl, numsl+1, ..., numsr-1, numsr] 
并返回其长度。如果不存在符合条件的子数组，返回 0 

## 解题思路
