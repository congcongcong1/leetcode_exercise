# [2563]. [统计公平数对的数目]

> 难度: [Medium] | 分类: [数组/链表/...] | 日期: 2026-3-7

## 题目摘要

给你一个下标从 0 开始、长度为 n 的整数数组 nums ，和两个整数 lower 和 upper ，返回 公平数对的数目 。

如果 (i, j) 数对满足以下情况，则认为它是一个 公平数对 ：

0 <= i < j < n，且
lower <= nums[i] + nums[j] <= upper

## 解题思路

### 第一反应
- 看到题目后最直觉的想法是什么？
  首先想到的是排序后利用二分查找的思路；
  但是又由于题目的解具有单调性，所以想到还可以使用双指针的方法
- 为什么这个想法行得通 / 行不通？
  行得通，可以用排序后二分查找或者双指针的方法来解决，

### 最终解法
- 核心思路：
1. 排序+二分查找
2. 排序+双指针


### 复杂度分析
| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 最优 | O(nlogn) | O(1) |
