# 双指针 / 滑动窗口 (Two Pointers / Sliding Window)

## 核心知识点
- **双指针**：两个指针按一定规则移动，减少嵌套循环
- **滑动窗口**：维护一个可变大小的窗口，O(n) 解决子串/子数组问题
- 常与排序、哈希表结合使用

## 常用解题模式
- **对撞指针**：有序数组两端向中间移动
- **快慢指针**：链表环检测、删除重复元素
- **滑动窗口**：固定/可变窗口大小
